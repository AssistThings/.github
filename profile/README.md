## Tecnologia assistiva aberta, feita com pesquisa

AssistThings é um projeto de pesquisa que reúne diversas universidades para criar
tecnologia assistiva **aberta** para apoiar pessoas com deficiência, com
**Inteligência Artificial** e **Internet das Coisas (IoT)**.

- **Aberto:** código, hardware e documentação livres para reproduzir e adaptar.
- **Privacidade:** o processamento acontece no aparelho. Imagens e rostos não vão para a nuvem.
- **Acessível:** usa componentes baratos e fáceis de encontrar (ESP32, câmeras UVC, impressão 3D).
- **Centrado nas pessoas:** as funções vêm de necessidades reais de quem usa.

**Conheça os projetos em [assistthings.github.io](https://assistthings.github.io)**

AssistThings es un proyecto de investigación que reúne a diversas universidades para

## Open assistive technology, built through research

AssistThings is a research project that brings together several universities to
build **open** assistive technology that supports people with disabilities, using
**Artificial Intelligence** and the **Internet of Things (IoT)**.

- **Open:** code, hardware and documentation are free to reproduce and adapt.
- **Privacy:** processing happens on the device. Images and faces never go to the cloud.
- **Affordable:** built with cheap, easy-to-find parts (ESP32, UVC cameras, 3D printing).
- **People-centered:** features come from the real needs of the people who use them.

**Explore the projects at [assistthings.github.io/en](https://assistthings.github.io/en/)**
